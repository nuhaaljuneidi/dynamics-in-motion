# Dynamics in Motion

An open collection of interactive, engineering-focused dynamics activities developed by Dr. Nuha Aljuneidi for mechanical engineering students and educators.

## Live learning site

Visit **[Dynamics in Motion](https://nuhaaljuneidi.github.io/dynamics-in-motion/)** to use the activities directly in a browser. No installation or student account is required.

## Activities

| Activity | Topic | Learning experience |
| --- | --- | --- |
| [01 - Distance and Displacement](https://nuhaaljuneidi.github.io/dynamics-in-motion/) | Rectilinear position | Move along a calibrated track and compare accumulated distance with signed displacement. |
| [02 - Motion Graph Translator](https://nuhaaljuneidi.github.io/dynamics-in-motion/motion-graph-translator.html) | Position, velocity, and acceleration graphs | Translate among related motion graphs and interpret slopes and areas. |
| [03 - Motion Vector Lab](https://nuhaaljuneidi.github.io/dynamics-in-motion/motion-vector-lab.html) | Vector kinematics | Explore position, velocity, and acceleration vectors through interactive motion. |
| [04 - Kinematics Relationship Lab](https://nuhaaljuneidi.github.io/dynamics-in-motion/velocity-axis-lab.html) | Choosing derivatives and integrals | Decide which relationship applies when motion is given as a function of time or position. |
| [05 - Example 10: Vertical Motion](https://nuhaaljuneidi.github.io/dynamics-in-motion/example-10-projectile.html) | Constant-acceleration projectile motion | Generate numerical examples by changing release height and flight time, then solve for launch velocity and maximum height. |

## Learning design

Each activity combines:

- A visual or animated motion model
- Live numerical measurements
- Guided engineering equations
- Immediate answer feedback
- Responsive keyboard-accessible controls
- A consistent course interface for classroom use

## Run locally

Clone the repository and open `index.html` in a modern web browser:

```bash
git clone https://github.com/nuhaaljuneidi/dynamics-in-motion.git
cd dynamics-in-motion
```

The activities use plain HTML, CSS, and JavaScript and do not require a build step.
